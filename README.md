# Marahib Couture

Site vitrine de l'atelier Marahib Couture (tailleur, Fass Mbao, Dakar).

- `index.html` : le site public. Le contenu vient de `data.json`.
- `admin.html` : l'administration (photos, textes, prix, avis…). Elle enregistre directement dans ce dépôt avec un jeton GitHub.
- `images/` : les photos.

Pour ouvrir l'admin : touchez 5 fois le bas de la page du site, ou allez sur `/admin.html`.
